# ⚡ EV Smart Dashboard — لوحة الشحن الذكية

تطبيق عربي/إنجليزي لتسجيل ومتابعة شحنات السيارة الكهربائية: الطاقة، التكلفة، المسافة، كفاءة الاستهلاك، التقويم، وأثر الشحن المنزلي على فاتورة الكهرباء.
**React + Vite + Tailwind CSS + Lucide Icons** — يعمل كـ PWA أو يُحوَّل إلى APK عبر Capacitor.
جميع البيانات تُحفظ على الجهاز (localStorage) بدون خادم.

*Developed by Eng. Fadi Abu Khalel*

## 1) كيف أعدّل التطبيق وأستخرج ملف APK (الخطوات بالتفصيل)

### الطريقة أ: من GitHub فقط (بدون تثبيت أي شيء على جهازك) ← الأسهل

1. افتح المستودع على GitHub، وادخل الملف الذي تريد تعديله (مثلاً `src/lib/i18n.jsx`).
2. اضغط أيقونة القلم ✏️ (Edit this file)، عدّل، ثم **Commit changes**.
   لرفع مجموعة ملفات دفعة واحدة: **Add file ▸ Upload files** واسحب الملفات إلى نفس المسارات.
3. ادخل تبويب **Actions** ← اختر **Build Android APK** من القائمة اليسرى ← **Run workflow** ← **Run workflow**.
4. انتظر 5–10 دقائق حتى يظهر ✅ أخضر. ادخل على التشغيل ← انزل لقسم **Artifacts** ← نزّل `ev-dashboard-debug-apk` (ملف zip فيه `app-debug.apk`).
5. فك الضغط وانقل `app-debug.apk` إلى هاتفك وثبّته (فعّل «السماح بالتثبيت من مصادر غير معروفة» للتطبيق الذي تفتح منه الملف).

> إن ظهر ❌ أحمر: ادخل على الخطوة الحمراء وانسخ آخر 20 سطراً من السجل. أغلب الأخطاء تكون في `npm install` أو `gradlew`.

### الطريقة ب: على حاسوبك

المتطلبات: Node 18+ و JDK 17 و Android Studio (أو Android SDK).

```bash
npm install
npm run dev            # معاينة في المتصفح على http://localhost:5173 أثناء التعديل
npm run build          # بناء نسخة الويب إلى dist/
npx cap add android    # مرة واحدة فقط (ينشئ مجلد android/)
npm run cap:sync       # بعد كل تعديل: بناء + نسخ إلى مشروع أندرويد
npm run cap:open       # يفتح Android Studio ← Build ▸ Build Bundle(s)/APK(s) ▸ Build APK(s)
# أو من الطرفية:
cd android && ./gradlew assembleDebug
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```

### ملاحظات مهمة عن ملف APK
- النسخة `debug` للتجربة والاستخدام الشخصي. لنشر التطبيق في Google Play تحتاج نسخة `release` موقّعة (keystore) وبناء AAB.
- لتحديث تطبيق مثبّت دون حذف بياناتك: ثبّت APK جديداً فوق القديم، بشرط أن يكون موقّعاً بنفس المفتاح (نسخ debug من نفس الجهاز/المشروع تتحدث عادةً فوق بعضها، أما المبنية من GitHub فتوقيعها قد يختلف؛ في هذه الحالة خذ **نسخة احتياطية JSON** من الإعدادات قبل حذف القديم واستعدها بعد التثبيت).
- تغيير اسم التطبيق: `capacitor.config.json` (`appName`) ثم `npx cap sync`. تغيير المعرّف `appId` يجعل أندرويد يعتبره تطبيقاً مختلفاً.

## 3) الميزات

- **الوضع والمظهر:** نهاري (Aqua Light) / ليلي (زجاجي Glass Aurora) / **تلقائي** يتبع الجهاز، وعربي (RTL) / English (LTR)، **ألوان قابلة للتخصيص** و**نوع الخط** و**حجم الخط**.
- **الترويسة:** «أهلاً، {اسمك}» (الاسم من الإعدادات، وفارغ = «أهلاً بك») + الماركة والموديل + سعة البطارية، بجانب صورة السيارة.
- **الرئيسية:** بانر الفترة بصيغة «من dd/mm/yyyy إلى dd/mm/yyyy» مع مفتاح **شهر عادي | دورة الفاتورة**، ورقم الطاقة، ومخطط مصغّر لآخر 3 أشهر، والمسافة والكفاءة إن توفرت قراءات العداد، وبطاقة التكلفة، وآخر **4 شحنات** بتفاصيلها. تغيير الفترة من زر «تغيير الفترة».
- **التنقل (5 تبويبات):** الرئيسية · **الشحنات** (قائمة وتقويم معاً بمفتاح تبديل) · **التحليل** · الفاتورة · الإعدادات.
- **التحليل:** مقارنة الأشهر العادية أو دورات الفاتورة (الطاقة، التكلفة، المسافة، الكفاءة) وجدول تفصيلي وكلفة الكيلومتر، وقراءات عداد السيارة.
- **قراءات عداد السيارة:** تُسجَّل من «التحليل» أو الإعدادات (أو من حقل العداد في الشحنة). المسافة في أي فترة = الفرق بين قراءتين عند حدّيها، وتُقدَّر نسبياً (≈) إن لم توجد قراءة عند الحد.
- **الفواتير (دورة الفاتورة):** عند وصول الفاتورة سجّل الفترة واستهلاكها الكلي (والمبلغ اختيارياً)، فيحسب التطبيق أثر السيارة بالتعرفة المتدرجة وينبّه إن اختلف الحساب عن مبلغ فاتورتك.
- **أسماء الأشهر بالإنجليزية** في المخططات والتقويم (Aug · Sep · Oct).
- **تصدير:** تقرير **PDF** للفترة المعروضة (ملخص + جدول الشحنات + أثر الفاتورة)، وCSV، ونسخة احتياطية JSON (تشمل الفواتير والقراءات).
- **الشحنة:** تاريخ بصيغة **dd/mm/yyyy** + SoC قبل/بعد (الطاقة تُحسب تلقائياً) + تكلفة بالسعر أو بالمبلغ + نوع الشاحن + عداد اختياري، مع تعديل/حذف بتأكيد.

## 4) كيف تُحسب الأرقام

- **الطاقة** = (SoC بعد − SoC قبل) ÷ 100 × سعة البطارية.
- **المسافة في فترة** = قراءة العداد عند نهايتها − قراءته عند بدايتها (استيفاء نسبي بين أقرب قراءتين، وتُقصّ الفترة إلى نطاق القراءات المتاحة). الكفاءة = طاقة الشحنات في نفس النافذة ÷ المسافة × 100.
- **كفاءة الشحنة الواحدة** (في قائمة الشحنات) تحتاج قراءة عداد في شحنتين على الأقل: الطاقة المستهلكة بين قراءتين = (SoC بعد الشحنة السابقة − SoC قبل الحالية) × السعة (+ أي شحنات وسيطة)، والكفاءة = الطاقة ÷ المسافة × 100.
- **أثر الشحن على الفاتورة** = كلفة(الاستهلاك الكلي) − كلفة(الاستهلاك الكلي − طاقة الشحن المنزلي)، أي أن السيارة تُحتسب آخر ما استُهلك فتقع في أعلى الشرائح. مثال: كلي 750، شحن 200 → الأساس 550؛ 50 kWh في شريحة 301–600 و150 kWh فوق 600. بالتعرفة المدعومة: 50×0.100 + 150×0.200 = **35.00 د.أ**.
- **التعرفة الافتراضية** (هيئة تنظيم قطاع الطاقة والمعادن، سارية من 1/1/2025، الشرائح شهرية وتراكمية): مدعوم 1–300 = 50 فلس، 301–600 = 100 فلس، أكثر من 600 = 200 فلس. غير مدعوم 1–1000 = 120 فلس، أكثر من 1000 = 150 فلس. القيم قابلة للتعديل من شاشة الفاتورة، والتعرفة تتغير بقرار رسمي فتأكد من فاتورتك. الحساب لا يشمل الدعم النقدي الثابت ولا المقطوعية الدنيا ولا بند فرق الوقود (يمكن إضافته كفلس/kWh).
- الشحنات المنزلية فقط (AC) تدخل في أثر الفاتورة، ويمكن إضافة نسبة فقد الشاحن.
